A chess engine in under 4 KB of Python: negamax alpha-beta search with quiescence, a transposition table, killer moves and piece-square tables, playing make.fun's eight-engine house gauntlet over its HTTP env. It searches to a fixed node budget, never a clock, so every game replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
